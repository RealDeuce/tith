## Security review

Type, Length, and common values can arrive before authentication. Type 0 is
rejected before its Length or Value is interpreted, permanently poisons the
streaming sequence state, and cannot be used as a resynchronization marker.
The owned parser returns no partial result after an invalid type. Canonical
integer decoding, checked platform conversion, exact-length reads, truncation,
allocation overflow, interrupted reads, and hard I/O failures are exercised at
the generic TLV boundary.

Signing uses the exact eight-byte `SignTLV` context including its terminal NUL.
Public keys and signatures are fixed-size types; every other length is rejected.
The Signature covers the literal SignedData Value bytes before nested values
are exposed as authenticated. The secret key is redacted from `Debug` and
cleared through `hydro_memzero` on drop. Every native initialization and
operation result is translated to a typed failure.

An anonymous Origin must carry its exact adjacent key. A non-anonymous Origin
accepts no supplied override and obtains one applicable key from the enclosing
resolver. An available Origin key always wins over SignedOrigin, and failed
verification is not retried under another identity. Thus attacker-controlled
key material cannot replace an authoritative key or turn one failed signature
into an alternate authentication attempt.

`verify_signed_tlv` returns SignedData only after authentication. The separate
unauthenticated accessor performs structural validation and exists solely for
the enclosing protocol's bounded error-response path; its result type carries
no authenticated identity. Enclosing acceptance tests demonstrate that data
from an invalid signature is neither processed nor acted upon. Unknown children
are an explicit enclosing-policy choice and never relax the order or
cardinality of defined children.

The common layer has no persistence, concurrent ownership, or recovery state.
Applicable malformed, overflow, truncation, resource, and I/O paths are covered
by the negative and fault-injection evidence above.
